🧠 Feynman Lab

  1. Pick one topic or chapter.
  2. Explain it in simple words, as if teaching a 12-year-old. No jargon.
  3. Find the gaps — wherever you got stuck or hid behind big words, write it down.
  4. Go back to your book or teacher, fix the gap, then explain again.

☁️ Sync & Backup

🖥 Cloud-folder sync (desktop Chrome / Edge)

Create a sync file inside your Google Drive, OneDrive or iCloud folder. The page keeps it up to date automatically and checks it again when you return to the tab. Link the same file on your other computer.

📱 Phone & any other device

Phones can't link a folder, so use quick backup and restore: save the file to Drive (or send it to yourself), then import it on the other device.

Importing asks whether to merge with this device's data or replace it. Merge keeps both sides, but an entry you edited on one device may then appear twice.

🌐 Online & offline use

Host index.html, sw.js, manifest.webmanifest and the two icon files together on GitHub Pages. Open the site once online, then use Chrome's menu → Install app / Add to Home screen. After that it opens and works with no internet. Your data always stays in this browser; only cloud sync and prayer-time lookup need a connection.

You are running . Everything you enter is saved instantly on this device, even offline. It reaches your other devices only through the cloud-file sync (desktop Chrome / Edge) or a backup you import.
